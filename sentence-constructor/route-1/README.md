# Route 1 — GPT-4o

This route began with a prompt-generation request in OpenAI Playground using GPT-4o. The resulting system prompt guides an English-to-Romanian learner through clues instead of giving the translation directly.

Design constraints:

- provide a useful vocabulary table;
- leave function words for the learner to determine;
- show content words in dictionary form;
- ask questions that lead the learner toward the correct tense, conjugation, and agreement.

See `prompt.md` for the system prompt and `testrun-gpt4o.md` for an example run.
