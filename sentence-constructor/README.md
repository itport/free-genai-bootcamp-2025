# Sentence Constructor

A prompt-engineering exercise for a Romanian tutor that helps a learner translate a target English sentence without revealing the final answer.

## Method

- `route-1` — prompt generated and refined using GPT-4o;
- `route-2` — an alternative prompt generated with o1-preview;
- `testing` — recorded tests and observations used to compare behavior and refine instructions.

The tutor is instructed to provide clues and a vocabulary table, omit function words that the learner should infer, use dictionary forms, and guide the learner through tense, agreement, and conjugation.

## Limitations

The examples are qualitative prompt experiments, not a statistically controlled model evaluation. Model behavior may differ as hosted models and system policies change.
