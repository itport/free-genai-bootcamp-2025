# Generative AI Bootcamp — Project Portfolio

Hands-on work completed during ExamPro's six-week **Free GenAI Bootcamp 2025**. The repository documents experiments in application development, prompt engineering, transcription workflows, and AI-system architecture.

## Projects

| Project | What it demonstrates | Technologies |
| --- | --- | --- |
| [Lang Portal](lang-portal/) | A Japanese vocabulary study portal. I completed missing Flask/SQLite API endpoints, normalized the API, implemented review tracking, and built an additional React frontend from scratch. | Python, Flask, SQLite, React, TypeScript |
| [Romanian Learning Assistant](language-learning-assistant/) | A Streamlit prototype for Romanian-language chat, YouTube transcript retrieval, media processing, cloud transcription, dialogue extraction, and vocabulary analysis. | Python, Streamlit, SambaNova API, YouTube Transcript API, Salad API |
| [Sentence Constructor](sentence-constructor/) | Prompt design and evaluation for an AI tutor that guides English-to-Romanian translation without revealing the answer. | Prompt engineering, GPT-4o, o1-preview |
| [GenAI Architecting](genai-architecting/) | An architecture exercise for a privacy-conscious, locally hosted language-learning service. | Systems design, open-weight models, capacity planning |

## Authorship and course material

## Running the projects

Each project directory contains its own setup instructions. Credentials are read from environment variables; copy the relevant `.env.example` file and supply your own values. No credentials or generated dependency directories are committed.
